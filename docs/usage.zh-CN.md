# 使用指南

[English](usage.md) · [文档目录](README.zh-CN.md)

## 筛选与播放历史

选择日期范围、时区、服务器和用户，确定仪表盘的统计范围。筛选条件保存在 URL 中，刷新页面或复制链接后仍可保留。分享链接不会授予访问权限：启用认证时，访问者仍需使用具有对应权限的凭据登录。

“正在播放”显示 Navidrome 上报的活动。播放历史、总量、小时与每日趋势、星期 × 小时热力图和排行榜使用已保存的记录。历史、排行和正在播放中的封面通过应用内带认证的缓存代理提供。

“最近播放”可分别设置桌面端和移动端显示的列，选择保存在当前浏览器中。信息按钮会说明未达到播放阈值就结束的会话。播放次数与收听时长的计算方式见[采集与统计口径](collection.zh-CN.md)。

## 排行、关系图与详情

艺人、专辑和曲目排行用于查看最常听的音乐。关系图可按艺人、专辑或客户端展示时间趋势、四个时段的分布，以及与紧邻的等长上周期之间的变化。图表支持切换播放次数与已记录的收听时长。

打开艺人、专辑或客户端详情，可查看当前范围内的总量、平均单次时长、曲目数、趋势、首次和最近播放、热门曲目、最近记录与上周期排名。单曲条目显示播放次数和记录时长。艺人与专辑详情可通过链接保留统计范围；客户端详情留在当前页面，分享 URL 中不包含客户端名称。

在**设置 > 偏好设置 > 合作歌手**中选择合并或分别显示。分别显示时，每位艺人从一条记录中获得一次归属，但全局播放次数、曲目数和时长仍只计一次，因此艺人之间的统计可能重叠。完整规则见[艺人归属（英文）](artist-attribution.md)与[图表说明（英文）](data-relations.md)。

## 收听回顾

选择一个自然月或年份，查看总量、连续收听天数、热门榜单、常听时段，以及与上周期的对比。月度视图按天展示，年度视图按月展示，图表可切换播放次数和收听时长。

“首次记录”指歌曲第一次出现在已保存的历史中，不能据此断定是你第一次听这首歌。回顾链接会保留日历周期、服务器、用户、时区与艺人归属范围。

## 外观与语言

主题模式与配色分别选择：模式支持跟随系统、浅色和深色。内置、Gruvbox、Catppuccin、Solarized、Nord、Dracula、Tokyo Night、Macchiato、Mocha 九个配色家族各有深浅两种变体，共 18 个预设。

高级外观设置支持微调六项核心颜色、实时预览、对比度检查、复制 HEX 色值，以及未保存改动保护。可以将单个预设的自定义颜色导入或导出为 JSON。偏好保存在当前浏览器中，应用于仪表盘、收听回顾、设置与 API 文档。

界面提供英语、简体中文、繁体中文、日语、德语、西班牙语和法语。

## 连接、权限与数据管理

管理员可在**设置 > 连接**中添加或禁用服务器，并根据连接诊断排查认证、TLS、网络、超时或采集器问题。一旦存在已保存的连接条目，应用就以该列表替代环境变量中的备用连接，即使所有条目都被禁用也不会回退。

管理员还可设置保留期，以及按用户导出、导入或删除收听数据。默认永久保留；设置 1–360 天的有限策略会启用自动清理。修改保留期或恢复数据前，请阅读[隐私说明（英文）](privacy.md)与[运维指南](operations.zh-CN.md)。

只读查看者可浏览仪表盘与收听回顾，无法打开设置或修改数据。部署者可通过[配置变量](configuration.zh-CN.md)把查看权限固定到某个服务器、某个用户名，或同时固定两者。
