# 用户告知模板

这是一份**草稿模板**，不是法律意见，也不是已经生效的政策。部署方必须自行编辑后才能使用。AI 不得代填机构名、法规名称、联系方式或承诺条款。

把每一个 `{{需用户人工确认/编辑}}` 换成你的决定。填写后的文本如果包含真实姓名、地址或联系方式，不要提交进本仓库。

---

## 本服务会做什么

`{{服务显示名，需用户人工确认/编辑}}` 会定期向你的 Navidrome / Subsonic 服务器查询「正在播放」状态，并在本机 SQLite 中保存达到阈值的收听记录，用于个人或家庭统计。

记录可能包括：账户用户名、曲名、艺人、专辑、客户端名称、播放时间和收听时长。这些属于收听行为数据，不是匿名遥测。

## 谁可以查看

默认情况下，未设置访问口令时，能访问该统计网页的人都能看到按用户名聚合的历史。是否启用口令、反向代理或仅内网访问：`{{需用户人工确认/编辑}}`。

## 保留与删除

播放明细默认永久保存，也可以在设置页改为 1–360 天。你可以按用户导出 JSON、导入或删除本服务数据库中的记录。备份副本里的数据删除由部署方负责：`{{备份与删除责任，需用户人工确认/编辑}}`。

## 联系

若你希望被停止统计或删除已保存的记录，请联系：`{{联系方式，需用户人工确认/编辑}}`。
