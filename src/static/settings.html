Data boundaries
  • Playback history, usernames, tracks, artists, albums, and client names are all behavioral data.
  • Finite retention automatically removes expired records. Apply-now and per-user deletion show an impact preview and require confirmation.
  • Exports contain data for the selected user only; export contents are not logged.
  • The operator must still confirm access boundaries, notice, backup locations, and the actual retention period.
